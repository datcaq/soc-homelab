## Overview

A personal Security Operations Center (SOC) home lab
designed to develop practical skills in security
monitoring, threat detection, log analysis, incident
response, and security automation.

## Project Objectives

- Build a virtualized SOC environment.
- Deploy and configure Wazuh SIEM.
- Monitor Windows and Linux endpoints.
- Analyze security logs and alerts.
- Develop custom detection rules.
- Map suspicious activities to MITRE ATT&CK.
- Investigate and document security incidents.
- Automate security tasks using Python.

## Planned Technologies

| Technology | Purpose |
|---|---|
| Wazuh | SIEM and security monitoring |
| Ubuntu Server | Linux environment |
| Windows | Endpoint monitoring |
| Sysmon | Windows event collection |
| Python | Security automation |
| Sigma | Detection engineering |
| MITRE ATT&CK | Threat classification |
| Wireshark | Network traffic analysis |
